I-0 · 技术基线 + RAG 最小闭环

✅ 已完成
出口：导入 → 嵌入 → 向量检索 → 引用问答的 API 闭环可用
  • 工程基线：Java 21 / Spring Boot 4 / Maven / Flyway / MyBatis-Plus，架构门禁脚本与统一异常响应
  • 导入链路：Markdown 按标题切分（码点安全滑窗）→ 逐 Chunk 嵌入 → Chroma 向量 + MySQL 原文
  • 检索链路：query 嵌入 → Chroma top-K（租户过滤）→ 阈值截断 → 引用组装；关键词降级硬约束（不可达即降级并标记 degraded）
  • 问答链路：证据为空直接拒答不调模型；引用由服务端组装，模型只写正文

I-1 · 账号 + 租户隔离 + 导入异步化

✅ 已完成
出口：新用户可注册并完成导入→问答；跨租户越权用例全通过
  • 账号体系：注册 / 登录 / 登出（JWT + BCrypt），登出后凭证经 Redis jti 立即失效，登录时序对未知邮箱保持一致
  • 租户隔离（架构不变量）：TenantLineInnerInterceptor 强制注入、UserContext 显式传递、Chroma fail-closed、越权与 ThreadLocal 污染回归
  • 安全合规：隐私明示 + 注册强制同意 + 同意版本留痕、SECURITY 前缀安全日志、401/404 语义区分
  • 导入异步化：202 + DB 队列 worker（FOR UPDATE SKIP LOCKED 认领）、指数退避重试、僵死接管、每租户并发上限；不用 @Async / 不用 MQ
  • 顺带清理：requestId 全链路、中文 2 字滑窗、向量候选池 ×3、reindex + 孤儿向量清理、Testcontainers 基类（Docker 开关式）、20 条评测集 + 格式门禁
